Getting started

DOMinion turns authored HTML pages and reusable fragments into complete static documents. Node.js is for building and previewing; the published site is served as ordinary HTML, CSS, assets, and any JavaScript you choose to author.

Requirements

Use Node.js 20 or newer to initialize, build, and run a local preview. Browsers and static hosts do not need Node.js or a DOMinion server.

Create a project

Initialize, install, and start the preview 
mkdir field-notes
cd field-notes
npx dominion init
npm install
npm run dev
The scaffold creates src/, shared/, public/, a Tailwind theme, and a root deployment configuration.

The preview watches the source directories, rebuilds into dist/, and serves that output locally. The starter can be replaced with this documentation site's examples as you learn the pieces.

Build before you browse

A file under src/ may contain DOMinion include tags and script timing directives. Those are source syntax, not browser features. Build first; open or publish files from dist/, never the unexpanded source tree.

npm run build
# Then serve or publish dist/
Keep the output boundary

Generated pages are self-contained HTML documents. Shared source files are expanded during the build and are not separate routes.
